# 온살 판매·광고 통합 대시보드

쿠팡 로켓배송 「온살」의 **판매(로켓 리포트)** 와 **광고(쿠팡 광고 리포트)** 를 한 화면에서 보고,
"오늘 뭘 해야 하는지"를 5분 안에 판단하기 위한 Streamlit 대시보드입니다.
엑셀 SUMIFS/INDEX-MATCH 수식 대신 **파일 2개 업로드 → 자동 누적 → 한 화면에서 판단** 구조입니다.

## 설치 (최초 1회)

Python 3.11 이상 필요.

```bash
pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

브라우저가 열리면 왼쪽 메뉴에서 화면을 고릅니다. (홈 → 판매·재고 → 광고 성과 → 키워드 분석 → 통합 손익 → 체험단 → 공급가 계산 → 발주 관리 → 파일 업로드·설정)

## 최초 1회: 기존 엑셀 데이터 이관

```bash
python scripts/migrate_legacy.py "sample_data/쿠팡_로켓_판매재고_관리.xlsx"
```

`일일데이터`(판매) 시트와 `체험단` 시트를 DB(`data/onsal.db`)에 적재합니다. 여러 번 실행해도 중복되지 않습니다
(같은 날짜는 덮어쓰기). 마지막 `일자(자동)` 수식 컬럼은 무시합니다.

## 매일 루틴 (5분)

1. **파일 2개 다운로드**
   - 서플라이어허브 → 로켓 리포트 → `basic_operation_rocket_YYYYMMDDYYYYMMDD.csv`
   - 쿠팡 광고 → 캠페인 리포트 → `A00000001_pa_total_campaign_시작일_종료일.xlsx` (**하루 단위** 또는 **월요일~일요일 한 주** 단위로)
2. **업로드**: `⚙️ 데이터 업로드·설정` → 파일 2개를 한꺼번에 끌어다 놓기 → 미리보기 확인
   (인식된 날짜, 온살 행 수, 신규 SKU, 미매핑 광고 옵션) → **[저장]**
3. **홈 확인**: `🏠 홈` 의 한 줄 요약과 **오늘의 액션 리스트** 를 위에서부터 처리
   (🔴 발주·품절 → 🟡 제외 키워드·손익분기 미달 → 🟢 입찰 상향)

> **광고 파일 규칙**: 광고는 **하루(일 단위)** 와 **월~일 한 주(주 단위)** 파일만 저장합니다. 월간·임의 구간 파일은 데이터가 겹쳐서 저장하지 않습니다.
> - 주 단위 파일을 올리면 그 주 안의 일 단위 데이터는 자동으로 대체됩니다(주 단위 우선).
> - 이미 주 단위 파일이 있는 날짜의 일 단위 파일은 건너뜁니다(바꾸려면 광고 데이터 관리에서 그 주 파일을 삭제).
> - 쿠팡윙(3P) 광고는 저장하지 않고 로켓배송(Retail)만 저장합니다. 기간은 파일명 끝의 날짜를 읽습니다.
> - 예전에 쌓인 광고 데이터를 비우고 처음부터 다시 올리려면 **파일 업로드·설정 → 광고 데이터 관리**(백업 후 삭제).
> - 같은 날짜/기간을 다시 올리면 덮어씁니다.

- **`실행.bat` 더블클릭** → 대시보드가 시작되고 브라우저가 열립니다. (종료: 검은 창 닫기)
- **`백업.bat` 더블클릭** → `backups/` 폴더에 엑셀 1개 + DB 사본이 날짜별로 저장됩니다(최근 30개 유지).
  복원하려면 `backups/onsal_날짜.db` 를 `data/onsal.db` 로 덮어쓰세요. 주 1회 정도 권장.
- 코드 관리는 Git(비공개 저장소). `data/`, `backups/`, `sample_data/` 는 `.gitignore` 로 제외되어 데이터가 저장소에 올라가지 않습니다.

## 공급가 계산 (🧮 공급가 계산 화면)

- **판매가·원가·수수료율**(보통 40%)을 넣으면 쿠팡 공급가(VAT 포함·제외), 개당 마진, 마진율(공급가·판매가 기준), 광고 손익분기 ROAS가 바로 나옵니다.
- 공식: `공급가(VAT 포함) = 판매가 × (1 − 수수료율)`, `공급가(VAT 제외) = ÷ 1.1(원 단위 반올림)`, `마진 = 공급가(VAT 제외) − 원가`.
- 상품별 표에서 값을 고치면 결과가 즉시 바뀌고, 최근 판매 데이터의 실제 쿠팡 공급가와 차이가 나면 경고합니다. 저장(관리자)하면 상품 마스터에 반영되어 다른 화면의 손익분기 ROAS에도 쓰입니다.

## 발주 관리 (📋 발주 관리 화면)

- **한눈에 보기**: SKU ID, 회사 코드, 유통기한, 현재고, 7일평균, 소진예상일, 발주 권장수량, 쿠팡 공급가를 한 표로. 회사 코드·유통기한이 빠진 상품은 경고.
- **발주서 만들기**: 표에서 발주할 상품의 **발주 칸을 체크**하고 **발주수량**(필요하면 기발주량)을 입력하면 발주서 미리보기와 **다운로드 버튼**이 나타납니다.
  내려받는 엑셀은 직접 만들던 `YYMMDD_매뉴얼 발주요청_업체_VF.xlsx` 와 같은 서식(11열, 초록 헤더, 재고일수·납품일자 수식)입니다.
  VENDOR ID / VENDOR NAME / 납품센터는 고정값으로 자동 입력(바꿀 일이 있으면 기준값 탭, 관리자). 같은 날 추가 발주는 "추가 발주" 체크 → 파일명 끝 `_추가`.
- **구글 시트에서 가져오기**: 판매가·쿠팡 공급가·유통기한·회사 코드를 정리한 구글 시트(공유: 링크가 있는 모든 사용자 – 뷰어)를 읽어 상품 마스터에 맞춥니다.
  바뀌는 칸을 미리 보여준 뒤 관리자가 반영합니다. 쿠팡 공급가가 있으면 수수료율을 역산합니다. 시트 주소는 DB 설정에만 저장됩니다(저장소에 올라가지 않음).
- 회사 전산(ERP) 자동 입력은 아직 연결하지 않았습니다.

## 여러 브랜드 수집

- 판매 CSV 에서 **기준값 탭의 "수집 브랜드"**(기본: 온살, 루메아카이브)에 해당하는 행을 모두 저장합니다. 브랜드를 추가하려면 쉼표로 이어서 적으세요.
- 신규 SKU 는 CSV 의 브랜드 값으로 상품 마스터에 자동 등록됩니다(마스터의 "브랜드" 칸).
- 화면 왼쪽 메뉴의 **🏷️ 브랜드** 선택(전체 / 온살 / 루메아카이브)으로 판매·재고·광고·체험단을 브랜드별로 나눠서 봅니다.
- 광고 행의 브랜드는 ① 광고 매핑표→SKU→마스터 브랜드, ② 없으면 광고 상품명에 브랜드명이 들어 있는지로 판별합니다.
- 같은 날짜 파일을 다시 올리면 **그 파일에 들어 있는 브랜드의 행만** 교체하므로, 다른 브랜드 데이터는 지워지지 않습니다.

## 핵심 지표 정의 (`src/metrics.py`)

- **판매량** = Σ출고수량 · **공급가매출** = 판매량 × 매입원가(쿠팡이 우리에게 지급, VAT 제외)
- **소비자가매출** = 판매량 × (판매가 − 할인) — 광고 전환매출과 비교할 때 사용
- **7일 평균** = 최근 7일 출고합 ÷ 7 (데이터 없는 날은 0) · **재고소진 예상일** = 현재재고 ÷ 7일 평균
- **발주 권장수량** = max(0, 7일평균 × 목표재고일수 − 현재재고) (올림, 기본 14일)
- **ROAS** = 전환매출액 ÷ 광고비 — 파일의 광고수익률 값은 버리고 원천 숫자로 재계산
- **TACoS** = 광고비 ÷ 소비자가매출
- **손익분기 ROAS** = 1 ÷ 마진율, 마진율 = (매입원가 − 원가) ÷ 소비자가
- **광고 기여 판매** = 광고 총 판매수량 × 묶음수량 · **오가닉(추정)** = 전체 출고 − 광고 기여 − 체험단
- **순이익** = 공급가매출 − 원가 − 광고비 − 체험단 비용

⚠️ 광고 전환매출은 소비자가 기준, 로켓 매출은 공급가 기준입니다. 통합 화면은 같은 기준으로 맞춰 계산하며
각 지표의 ⓘ 툴팁에 근거가 적혀 있습니다. 체험단 구매도 출고수량에 포함된다고 가정하며,
`체험단 제외 기준` 토글로 순수 판매를 볼 수 있습니다.

## 설정·마스터 파일 (대시보드 안에서도 편집 가능)

- `config/settings.yaml`(최초 기본값, 이후 수정은 DB 에 저장) — 브랜드명, 목표재고일수, 신호등 기준, 제외 키워드 기준 광고비, 최소 클릭 수, 급감 기준 %, 체험단 대행비 기본값(0=직접 입력) 등
- `config/product_master.csv` — SKU별 품목명·판매가·할인·원가·운영중·광고명키워드
- `config/ad_sku_map.csv` — 광고 옵션ID ↔ SKU ID, 묶음수량. 광고 업로드 시 상품명으로 **초안**이 자동 생성되며
  (`비고`에 "자동추정") 확인 후 확정합니다. 매핑 안 된 옵션은 통합 분석에서 "미매핑"으로 따로 경고됩니다.
- 신규 SKU가 판매 데이터에 처음 나오면 마스터에 자동 추가되고 "가격 미입력" 경고가 뜹니다.

## 알려둔 한계

- 주 단위 파일은 하루씩 나눌 수 없어, 일 단위 분석에는 하루 단위 파일이 있는 날만 쓰입니다. 통합 손익은 선택한 주/일 합계 기준으로 판매와 맞춥니다.
- 오가닉 판매는 "전체 − 광고 기여 − 체험단"의 추정값입니다.
